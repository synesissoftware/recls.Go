# recls.Go - Example - **search_simple**


## Summary

Recursively searches for files under a root (default `.`) matching a
pattern (default `*`), printing each entry's search-relative path.


## Source

* [examples/search_simple/main.go](./search_simple/main.go)


## Execution

```bash
go run ./examples/search_simple
go run ./examples/search_simple /tmp '*.go'
```
